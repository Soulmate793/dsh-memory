# 常见问题

## 安装与运行

### 需要什么依赖？

只需要 Node.js >= 20，**没有任何 npm 依赖**。

### 怎么确认插件装好了？

重启 DSH 后，agent 应该能看到 7 个 `memory_*` 工具；
直接调用 `memory_stats` 能返回记忆库统计就说明正常。

### 装完没有工具？

- 检查 `cordis.patch.yml` 里的 `memory` 行是否被启用
- 检查 profile 的 bundle 列表是否包含这个包
- 重启 DSH

---

## 数据

### 记忆存在哪里？

默认 `~/.dsh/qq-memory/`，可以用配置或环境变量 `MEMORY_DIR` 改。

### 会丢吗？

持久化在 JSON 文件里，重启不丢。建议定期备份：

- `memory.json`（数据）
- `memory-chain-key.pem`（证明历史用的私钥）

### 能直接在文件里改记忆吗？

可以，但改了之后 `memory_chain_verify` 会报「mismatch」——这正是哈希链的用途：**改了会留痕**。

### 怎么清空记忆？

停掉写入进程，删除 `memory.json` 与 `memory-chain*.jsonl`（私钥可保留），重启即可。

### 支持多少条？

默认上限 50 万（`maxItems`），超出按强度淘汰最弱的。

## 召回

### 为什么搜不到某条记忆？

- 线索词没命中（关键词召回要求至少一个特征重合）
- 记忆已衰减归档（可 `include_archived=true`）
- 在 `vault` 区且没开 `include_vault`
- 被容量淘汰

### 为什么搜出来的是别的？

召回是「线索依赖」的，不是精确查询；相关度只占 55%，强度/近因/重要度也会影响排序。可以缩小 `zone` 或换更具体的线索。

### 支持语义搜索吗？

核心插件默认只做关键词召回。要语义召回需要本地 embedding 服务 + 向量索引（见 `docs/design.md` 第 8 节）。

## 遗忘与巩固

### 为什么记忆变淡了？

艾宾浩斯衰减：不用的记忆按指数曲线下降。重要/带情绪的记忆衰减更慢。

### 怎么让某条记忆不被忘？

- 提高 `importance`
- 多召回它（提取强化）
- 设为 `pinned`（不参与淘汰）
- 或放进 `self` / `vault` 区（不衰减）

### 巩固会不会删记忆？

不会物理删除。合并后原情节记忆归档，`state=archived`，仍可用 `include_archived` 查到。

## 哈希链

### 链断了怎么办？

先看 `memory_chain_verify` 的 `errors`：

- `seq 不连续` / `prevHash 不衔接`：通常是并发写或手动改文件
- `hash 不一致`：内容被改过
- `签名无效`：私钥/公钥不匹配或事件被伪造

修复方式：停写入进程，备份坏链，用当前 `memory.json` 重建链（会丢失历史事件列表，但能恢复一致性）。

### 需要公链吗？

不需要。这是本地审计链，防的是「悄悄改记忆不留痕」，不是防整机被接管。

### 私钥丢了会怎样？

旧链无法再验证签名。记忆数据本身不受影响，但审计历史作废。

## 隐私

### 会联网吗？

不会。插件没有任何网络请求。

### `vault` 区安全吗？

目前只是**不参与召回**（默认不返回、群聊永远不可见），文件仍是明文。需要加密存储请关注路线图。

### 仓库里有我的数据吗？

没有。仓库只包含代码、文档、图标；`.gitignore` 已排除数据文件与密钥。

---

## 性能

### 50 万条会不会很慢？

关键词召回是全量扫描 + IDF 计算，2 万条约几毫秒；到 50 万条会到几百毫秒级，建议配合向量索引或分片。

### 多进程同时写会坏吗？

有文件锁保护；哈希链追加也是锁内读链尾，避免断链。但**不要用外部脚本绕过 MemoryStore 直接写 memory.json**。

---

## 开发

### 怎么跑测试？

```bash
node --test tests/*
```

### 怎么加一个新的记忆区？

1. 在 `lib/core/zones.mjs` 的 `ZONES` 里加一项（label/decayMultiplier/weight）
2. 在 `classifyZone` 里加分类规则
3. 迁移旧数据（重新打 zone 并对账哈希链）

### 怎么换 embedding 模型？

改 `lib/core/vectors.mjs` 的 meta（model/dim），重建索引即可。
